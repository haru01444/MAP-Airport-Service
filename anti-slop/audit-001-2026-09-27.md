## Detailed Findings & Remedies

### Finding #1: Eyebrow Container / Badge Violations (HIGH)
- **Violation:** `R-09` (Badges without purpose) and `AGENTS.md` Subheader Rule.
- **Details:** 7 sections contained pill badge containers (`borderRadius: 100`, background fill, borders) parking category labels above headers.
- **Remedy:** Removed all pill background containers and replaced with standard orange dash (`width: 20px`, `height: 2px`, `background: #F5A623`, `borderRadius: 2px`) + uppercase text (`letter-spacing: 0.12em`, color `#1967D2` on light backgrounds, `#fff` / `#4A9EF5` on dark backgrounds).

### Finding #2: Mobile Typography & Spacing Alignment (HIGH)
- **Violation:** `R-03` (Mobile Responsiveness) and `AGENTS.md` Mobile Rules.
- **Details:** Headlines and text scale were not calibrated for screens below 768px.
- **Remedy:** Added responsive CSS classes (`training-hero-title`, `training-hero-desc`, `training-section-h2`, `training-stat-num`, etc.) with `@media (max-width: 768px)` rules matching exact specifications:
  - Hero H1: 32px / line-height 1.12
  - Hero Paragraph: 14.5px / line-height 1.7
  - About/Section H2: 25px
  - Stat Numbers: 22px monospace (700)
  - Eyebrow margin-bottom: 12px, H1/H2 margin-bottom: 16px, Header wrapper margin-bottom: 28px.

### Finding #3: Stacked Concentric Dashed Circles (MEDIUM)
- **Violation:** `R-07` (Background Patterns without purpose).
- **Details:** 3 layers of huge concentric dashed circles overlaying the Program header section background.
- **Remedy:** Removed concentric dashed circle overlays to clean up background visual noise.

### Finding #4: Glassmorphism Dose Cap Breach (MEDIUM)
- **Violation:** `R-10` (Glassmorphism Dose Cap - Max 1-2 elements).
- **Details:** 6 facility cards each used `backdropFilter: "blur(12px)"`.
- **Remedy:** Replaced glassmorphism blur on grid cards with solid dark elevated cards (`background: "rgba(255,255,255,0.04)"`, subtle border `#1E2D5A`).

### Finding #5: Organic Blob Accent Shapes (MEDIUM)
- **Violation:** `R-01` & `R-22` (Decorative Shapes without connection).
- **Details:** Asymmetric organic morphing blob backdrops behind program images.
- **Remedy:** Replaced morphing blob shapes with crisp, subtle rectangular card accent frames.

### Finding #6: Stat Numbers Monospace Styling (MEDIUM)
- **Violation:** `R-06` (Typography) & `AGENTS.md`.
- **Details:** Stat counters (7+, 4, 4, 8+) used standard Poppins font.
- **Remedy:** Applied `font-family: var(--font-geist-mono), ui-monospace, monospace` for stat numbers.

### Finding #7: Em Dash in Metadata Title (LOW)
- **Violation:** `R-02` (Copywriting).
- **Details:** `title: "MAP Training Center — Pusat Pelatihan Aviasi Indonesia"`.
- **Remedy:** Changed to `title: "MAP Training Center : Pusat Pelatihan Aviasi Indonesia"`.
